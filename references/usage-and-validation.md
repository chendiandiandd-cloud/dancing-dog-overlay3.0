## 依赖与参数

Python 3.10+、NumPy、Pillow、OpenCV 4.x、系统 FFmpeg/ffprobe（libx264/AAC）。依赖见 `scripts/requirements.txt`。OpenCV 4.x自带经典Haar/HOG；不另下载重模型，不调用生成模型、神经分割或运行时视觉LLM。缺检测器时告警，不能声称已实现人物避让。

从Skill根目录执行：

```bash
python3 scripts/render_overlay.py --inputs '/path/image.webp' '/path/movie.mp4' --output-dir temp_data/results --seed 42 --quality hd
```

| 参数 | 行为 |
|---|---|
| `--inputs FILE ...` | 最多64个；多图多视频/混合批次，逐文件独立MP4；单worker |
| `--image-duration` | 图片默认5秒；动态GIF/WebP只用EXIF转正后的首帧 |
| `--quality preview\|hd\|source` | 最长边1280/1920/原尺寸；只缩小不放大，奇数宽高右侧/底部补1像素 |
| `--seed` | 复现狗、动作相位及近似同分候选；需相同输入/依赖/源码/素材版本 |
| `--placement-mode auto\|corner` | 支撑面与安全边角联合候选，或强制边角；都遵守保护与全动作边界 |
| `--height-ratio` | 手动请求完整动画画布高比例，不是可见角色高度；默认auto候选0.40/0.36/0.32/0.28/0.24，实际不得低于24%，无合法落点失败。显式尺寸/anchor及corner沿用旧行为例外（无显式尺寸时旧0.24/0.22/0.20/0.18及旧小号fallback） |
| `--allow-special-fallback` | 默认关闭；授权后严格失败先body-relaxed保留脸/文字，若无位或最小边距<0.055则尝试detected-relaxed内侧候选；默认保持24%–40%与内侧偏好，始终保留人工禁区/完整边界 |
| `--anchor X Y` | 归一化脚底，不改变指定点；边界受限可缩小，否则失败。始终固定（即使tracking=flow）。绕过四角小保留区，但不绕过检测人脸、人物、衣服及文字保护 |
| `--dog-id` | 仅首镜头指定；后续洗牌袋相邻不重复 |
| `--cuts '1,2'` | 人工秒切点覆盖自动检测；空串整片一个镜头；不对不同长度素材盲套 |
| `--tracking auto\|off\|flow` | 默认auto；off固定；flow明确尝试二维LK/RANSAC，失败静止回退；见下文 |
| `--plan-only` | 写分析计划/跟随统计，不生成MP4，拟输出路径不能当成片交付 |
| `--music FILE` | 显式替换原音轨，循环/截断到片长并AAC；不默认加音乐 |
| `--timeout` | 每个FFmpeg阶段最大秒数，默认600 |

默认视频保留有效解码时长和第一条原音轨，小狗静音；兼容AAC/MP3/AC3/EAC3/ALAC尝试copy，失败或不兼容转AAC且日志化。静态图无音乐时静音。VFR通过fps滤镜转换CFR（有效fps限制1–60），不保留VFR时间戳，允许约一个输出帧的时长差；旋转在FFmpeg自动转正后统一分析/合成坐标，不二次手工旋转。

## 输出契约

任务输出 `output-dir/task_<time>_<uuid>/`：逐文件MP4/JSON与批次summary，目录可复用、重复输入不撞名。`output-dir/summary.json`为最近完成任务副本；并发以最后完成者为准，隔离任务记录不丢失。全部成功退出0，部分/全部失败1，参数错误2；失败JSON保留，仍交付成功文件。

每文件含 `input、output、status、shots、timings、warnings、verification、tracking_analysis_seconds`。每镜头含 `start/end、dog_id、anchor、height_ratio、phase_frames、placement、motion`。跳过光流时每镜头含`motion.skipped_reason`；整片无候选时含`tracking_skipped_reason`且`tracking_sampling_fps=null`。anchor是实际整数画布取整后的归一化脚底；height_ratio是实际画布高/显示画高。

`analysis`另含实际`sampling_fps`、`sampled_frames`、`cut_events`（RGB差分/直方图、HSV、空间亮度、边缘、近期基线及触发规则）、`detector_stats`（返回抑制/极端亮度帧计数）、`cut_time_resolution_seconds`及`limitations`。24fps源自动时间分辨率为1/24秒（约0.041667秒）；是CFR帧格精度，不是VFR原始PTS保真保证。自动镜头短于0.25秒合并；手动切点仍按输出CFR向上量化，源fps超过60或VFR可能有原时间偏差。引擎/检测器版本进入缓存签名，1.3.0缓存不会复用。

`placement`记录源/输出素材分辨率、完整周期边界、尺寸候选联合分数、选择理由、检测人脸/人物/文字近似框、衣服并集mask、保护采样数、支撑几何、screen_sticker/surface模式。`ground_anchored=false`不声称真实地面理解；当前所有模式均 `contact_shadow=false`，不会给无支撑贴纸添加假落地阴影。

`motion`记录实际mode与reason、全片尝试/接受比例、局部/相机对数、平均RANSAC置信度、拒绝原因、冻结时间、二维轨迹和最大位移。**accepted_pairs是图像运动估计通过数，不是已经随动的成片帧数；mode=off时即使背景匹配很好，成片仍然固定。**

## 经典保护、支撑面与跟随

### 主体与衣服

- 分镜分析最长边480，自动检测遍历有效CFR全帧（1–60fps）；辅助特征在160×90提取、空间亮度/边缘在64×36比较。RGB/HSV颜色分布与去均值空间亮度、边缘共同判断；空间/边缘孤立峰值及近期运动基线弥补同色人物/景别切换漏检，不要求RGB直方图必然改变。队列持续观察每一帧，候选延迟0.25秒确认；返回原布局及颜色的脉冲连同恢复边沿一起拒绝。全幅平均亮度>0.85或<0.035的极亮/暗帧及其0.25秒恢复段保守不独立切镜。快速运动、深暗场景、渐变及闪光附近真实剪辑仍可能误/漏检，人工cuts可修正。手动cuts分析仍最高12fps，切点不由检测器修改，输出按CFR向上量化。
- 不只第一帧：全片均匀保护采样间隔 `max(0.5s,片长/240)`，末帧补采，每镜头再加入切入代表帧；短片约2fps。图片最长边640。保护区域取镜头采样并集，移动腿脚/衣服不再只看切入帧。
- Haar使用5邻居；面积>7.5%的大近景脸要求额外本地眼部级联证据，面积>30%或横向>65%/纵向>60%画幅的大框不当成人脸。小脸不要求眼证据以免远景漏检。不能保证宠物不产生眼部误检、侧脸/墨镜真实人脸不漏检。
- 人脸硬保护；近似身体向下8.5脸高，普通脸向两侧约1.25脸宽，近景脸（宽>画宽28%）额外左右扩张限制为画宽4.5%，避免一张宠物/大脸把整幅下部封死。HOG只接受权重>=0.5且面积<60%、宽度<80%的框；HOG也不是语义保证。
- 脸/颈部局部GrabCut，图割最长边256、两次迭代，扩展至约9脸高。肤色与衣服颜色不同且两侧背景颜色均明显不同的局部衣服核心才加入微小确定前景种子；保留与脸/衣服种子连通的区域；对衣服种子另做有面积门限的Lab颜色连通生长，补救肤色与裙子颜色不同时图割只保住脸的问题。面积门限与膨胀避免漏保护边缘。不能识别所有长裙/宠物/手/背包，分割可能只保住上半身或误保背景；身体近似框仍提供保守防线。

### 文字与四角

形态梯度、连通细笔画、横向闭运算、长宽比/密度筛选文字形状；兼容已连接成整行的描边字幕。**不是OCR，不理解文字内容。** 四角无条件保留各画宽17%×画高5.5%的小块，避免角落水印；并非保留全部四角或字幕区。自然树叶/草地可能被误判文字，透明/低对比/超小字幕仍会漏。因而可能缩小或退到上角，必须查看截图，不能宣称所有水印/字幕都被避让。

### 支撑面与安全贴纸

排除y<0.52候选；Hough线必须在实际脚底约60%画布宽跨度有至少72%连续边缘观测，并检查所有时间样本，不能只凭一条长线的端点。比较材料条带、极性、临近竖结构、下部偏好、远景线/画底边框惩罚；拒绝平滑蓝色大区域及缺材料证据的强水平波纹倾向/碎线。不是水面/草地语义分类；绿色水面与草地仍可能混淆，运动支撑面时序连续性检查会偏保守。

证据不足时 `screen_sticker` 选安全边角/外围网格（默认底部留6.5%边距，必要上角），诚实说明是屏幕贴纸，非地面锚定，无接触阴影。每帧只新增一只狗，不检测或清除原画面已有狗；再次套参考效果片会同时看到已有狗和新增狗。

### 有限范围二维跟随

- 对视频从开头到结尾另做最长边320/最高6fps流式采样，不因开头纹理好就认定整片可跟随。每切镜单独重置脚底和累计位移，不穿越切镜拟合。
- 当前脚底周围局部背景Shi–Tomasi特征，排除全片人物/衣服/文字并集；双向稀疏LK，回投误差<1.2px；局部失败尝试排除保护区域的相机背景RANSAC部分仿射。
- 至少8个内点、内点比例>=0.65、中位残差<=1.2px；相邻缩放0.96–1.04/旋转<=3°/位移范围限制。只移动二维脚底点，不给狗施加尺度或旋转变形，不宣称三维跟踪、透视恢复或遮挡。
- 移动后的完整RGBA画布、采样端点之间的扫掠矩形均不能越界或穿过保护区域；输出帧线性插值，仅一次整数位置取整。
- flow首次置信度/边界/主体冲突失败后冻结在最后安全位置；后续继续统计但不重新捕获跳回。auto仅surface候选考虑运动；全镜头通过比例<85%或任何冻结则整镜头改固定初始安全位置。非稳定背景/screen_sticker保持固定，避免把狗绑到移动背包、腿脚或水波上。
- 人工anchor始终固定，off不增加光流解码；auto的screen_sticker跳过光流，记录每镜头`skipped_reason=safe_screen_sticker`，未尝试时`accepted_ratio/mean_confidence=null`（不是0%匹配率）。整片没有flow候选时直接跳过额外解码，`tracking_skipped_reason=no_flow_eligible_shots`。混合片只在surface镜头计算LK，切镜仍重置；显式flow保持原行为。全片主体保护采样不受影响。不新增debug架构，需运动诊断时显式flow配合plan-only，不把该诊断计划误当默认auto效果。
