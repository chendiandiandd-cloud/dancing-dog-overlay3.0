# 完整功能无损压缩版（Skill v1.3.6）

## 压缩方式与兼容性

仅改变 RGBA 缓存 NPZ 容器的压缩方式：ZIP_DEFLATED → ZIP_LZMA；保留全部 16 只狗、827 帧、原尺寸、颜色、透明通道、透明像素下的 RGB、固定脚底锚点及动作周期。正常合成仍调用原 `np.load(..., allow_pickle=False)`，选位、分镜、跟随与合成算法不变，引擎版本保持 `overlay-1.3.5`。Skill 发布版本为 `1.3.6`，不代表另一次效果算法升级。

环境需具备 Python 标准库 `lzma`。源码、16 份原视频、离线分割试验模型及回归测试完整保留。原生 ZIP 外包使用标准 Deflate，可正常解包；内部 NPZ 由 Python 读取，不需要用户手动解压。

缓存文件字节哈希发生变化，`assets/dog_manifest.json` 已更新对应 SHA-256、npz_bytes 和无损存储说明；解压数组逐帧哈希另用于像素一致性验证。不要把旧的文件哈希清单搭配新缓存。

## 保留的效果限制

此次目标是缩包且保持效果，不修改既有选位规则。历史两张图片仍有贴边风险，湖边图片仍偏边缘，树林人像图片的大贴纸仍可能遮挡下半身；授权特殊模式允许部分遮挡不等于视觉上总符合用户喜好。源素材原有循环接缝、细边污染与真实快剪误/漏检限制也仍保留。不能把无损压缩说成已修复这些问题。

运行时报告、逐帧哈希、复测 MP4、用户输入和预览拼图只存 `temp_data/lossless/`，不纳入共享 Skill 包。

## 维护

现有缓存重新压缩使用 `scripts/lossless_cache.py`，支持 `--assets-dir`、`--work-dir`、`--report`；重建 RGBA 使用 `scripts/prepare_assets.py`，今后默认生成 LZMA NPZ。维护操作应停止渲染/预处理，按素材来源文档的恢复说明处理异常；不用为缩包重新抠绿或调用生成模型。
